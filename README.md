A student-focused academic support platform for engineering students. Get last-minute revision materials, track academic calendars, develop skills, and prepare for placements.

Built for students who need quick access to study materials and career development resources.

## � Installatmion

1. **Clone the repository**
   ```bash
   git clone https://github.com/Aditibasavaraj/lastminutehub.git
   cd lastminutehub
   ```

2. **Open with Live Server**
   - Install [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension in VS Code
   - Right-click `index.html` → "Open with Live Server"
   - Visit `http://127.0.0.1:5500`

3. **Alternative: Direct browser**
   - Simply open `index.html` in any modern browser
   - All features work without a server
